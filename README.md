# disease-diagnoser-app
A mobile application built using **MIT App Inventor** that assists users in identifying possible diseases based on their symptoms.  
The app also provides emergency contacts, health reminders, and language translation support to make healthcare guidance more accessible.

---

## 🚀 Features
- Diagnose common conditions:
  - COVID-19
  - Chicken Pox
  - Chikungunya
  - Dengue
  - Influenza
  - Malaria
  - Smallpox
  - Tetanus
  - Tuberculosis
- Symptom-based diagnosis flow
- Emergency contacts page
- Daily health reminders (including water reminder)
- Multi-language translator
- Credits page & error handling screens

---

## 🛠️ Tech Stack
- **MIT App Inventor** (drag-and-drop visual programming)
- Rule-based logic using App Inventor blocks
- Multi-screen design
